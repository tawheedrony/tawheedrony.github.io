# tawheedrony.github.io

Personal website, <https://tawheedrony.github.io>, built with [Jekyll](https://jekyllrb.com/). The design is adapted from [Jon Barron's website](https://github.com/jonbarron/jonbarron.github.io).

| What                  | Where                       |
| --------------------- | --------------------------- |
| Home page, papers     | `index.html`                |
| News items            | `_news/` (one file each)    |
| Styles                | `assets/css/barron.css`     |
| Mosaic project page   | `mosaic/` (standalone)      |
| CV                    | `assets/pdf/`               |

Deploys to GitHub Pages on push to `master` via `.github/workflows/deploy.yml`.
